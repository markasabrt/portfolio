### >>>>Project: [Giygas experiment]
Markdown

Listen to the track here:
[Play Audio](./tracks/Giygas.wav)

Genre: Experimental Chiptune / Synth-wave

   Creative Concept & Inspiration
   
I did not have a specific goal with this track but i ended up mixing video game sound effects and pop music drums.
#### Technical Workflow
*   The Drums: I used the drum layout from Dead or Alive's "You Spin Me Round (Like a Record)" (transcribed by Captain Pikant). Instead of using a standard loop, I mapped the individual drum samples into FL Studio's FPC and programmed a repeating 3-bar drum loop to drive the rhythm.
*   Main melody: The main lead relies on a Megaman soundfont.
*   Sound Design
    *   Intro: I sampled the EarthBound Giygas scream raw (pitched up) to create an eerie tension before the synth kicks in.
    *   Outro: At the end, I chopped the Giygas scream into short bursts which ended up creating a really nice effect. 
    * I exported that chopped sequence, brought it back into the sampler, reversed the audio, and layered it heavily to create a chaotic sound for the track's outro.

### Software & Environment
*   DAW: FL Studio
*   Operating System: Windows
*   Tools: Soundfonts, synthesizers, chopping samples.
